# Juego de Puzzles

Este juego fue desarrollado para pobrar las transformaciones en Unity.
El objetivo es mover todas las cajas a los distintos puntos objetivo en el mapa, como en el clásico Sokoban.

## Controles
- WASD - moverse
- R - reiniciar nivel
- Esc - salir

## Descargar
Ver la sección [Releases](https://github.com/MarcoAntonioPdLA/CGVCM-Lab02-Puzzles/releases) para descargar el ejecutable.
